# AIWITHAK Portfolio

Complete Next.js portfolio for **AIWITHAK.INFO**.

## Included

- AI engineering and Responsible AI positioning
- Caffeinated Professor flagship case study
- WePOS capstone and Project Manager responsibilities
- AI ethics knowledge and research interests
- Publications and research manuscripts
- Responsive design with no LinkedIn or GitHub links

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Before deployment

Replace `your-email@example.com` in `app/page.tsx` with your email address. Then deploy to Vercel and connect `AIWITHAK.INFO`.
